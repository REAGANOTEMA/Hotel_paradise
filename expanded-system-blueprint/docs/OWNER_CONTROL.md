# Owner control model

Two owner accounts can be represented as separate users with an Owner role. Owner/director dashboards should expose cross-property KPIs, revenue, POS activity, cash movement, inventory exceptions, refunds/voids, approvals, audit events, staff activity and EFRIS status.

Sensitive actions should require explicit permission and, where configured, second approval. Every edit, refund, void, stock adjustment and financial posting should create an audit event.
