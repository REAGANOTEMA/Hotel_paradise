# HOTEL PARADISE ON THE NILE — DESIGN SYSTEM

## Palette
Luxury Gold: #C9A227
Deep Navy: #071A33
Nile Blue: #0B5D78
Nebula Blue: #1E3A5F
White: #FFFFFF
Soft Ivory: #F8F5EC
Charcoal: #111827
Ugandan accent: #000000 #FCDC04 #D90000

## Visual language
- Elegant serif display headings + clean sans-serif body text.
- Large photography with subtle dark overlays.
- Gold used for premium highlights, not as a full-page background.
- Navy for navigation and primary surfaces.
- Nile Blue for links, secondary actions and water-inspired accents.
- White/ivory for readable content surfaces.
- Rounded cards used sparingly.
- Strong whitespace and clear hierarchy.

## Motion
- 180–350ms transitions.
- Fade/slide reveal on section entry.
- Gentle hero image zoom.
- Button hover lift of 1–2px.
- Respect prefers-reduced-motion.
- No distracting continuous animations.

## Footer
Footer includes three thin horizontal accent stripes:
black / yellow / red, with a subtle Ugandan flag motif.
Do not overpower the hotel brand.

## UX
- Booking CTA always visible on desktop.
- Mobile bottom booking CTA.
- WCAG-aware contrast.
- Keyboard navigation.
- Loading/skeleton states.
- Empty/error/success states.
- Confirmation before destructive financial actions.
