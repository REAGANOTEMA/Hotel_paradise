# WEBSITE SQL COVERAGE

The public Hotel Paradise on the Nile website is currently primarily a frontend.
It should use the same `hotel_paradise_nile` database/API as the management system.

Website-specific SQL belongs here only when the website actually requires persistent
data that is not already represented by the hotel system (for example website settings,
CMS content, enquiries, or integration metadata).

Do not duplicate guests, rooms, reservations, POS, payments, or hotel operational
tables in a second website database.
