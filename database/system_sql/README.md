# SYSTEM SQL — HOTEL PARADISE ON THE NILE

This folder contains every SQL file intended for the hotel management system.

## Recommended installation
1. Run `04_SYSTEM_INSTALL_ALL.sql`.
2. Run `05_SYSTEM_VERIFY.sql`.
3. Configure the PHP application's database credentials.

## Other files
- `01_SYSTEM_SCHEMA.sql` — core schema
- `02_SYSTEM_SEED.sql` — seed/reference data
- `03_SYSTEM_MENU_ALACARTE.sql` — menu/al-a-carte data
- Any additional SQL files in this folder are preserved source SQL from the project.

Do not create a second competing hotel database unless the application architecture is deliberately changed.
